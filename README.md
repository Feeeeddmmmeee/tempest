Tempest is a command line application that generates cozy rain simulations with an occasional lightning flash right in your terminal emulator of choice while being fully customizable through CLI options.

## 🚀 Installation / Building from source
As of now to install and use the program you have to build it yourself. Start off by cloning the repository to your local machine and making sure you have all the [required dependencies](#-Dependencies):
```sh
git clone https://github.com/Feeeeddmmmeee/tempest
cd tempest
```
Then run one of the built in scripts to build the project and execute the binary:
```sh
./run # or ./debug - both are valid build scripts (though run is preferred for standard use)
./build/tempest
```

## 📦 Dependencies
Note that the program versions are just the ones I happened to have on my machine at the time of writing and older ones will most likely work just fine.
- Cmake 4.4.5+ and a C++ 20 compiler
- Notcurses 3.0.17+
